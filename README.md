# 个人工作生活台

只给自己用的本地工作台：九个模块、一块数据文件、不登录、不联网。关掉浏览器、重启电脑，数据都还在。

## 怎么启动

第一次使用，先在本目录跑一次：

```
npm install
npm run build
```

之后只要**双击 `start.bat`**（或者在本目录执行 `npm start`）。

- 服务地址：`http://127.0.0.1:4173`，启动后会自动打开浏览器。
- 重复双击不会开第二个实例：检测到端口被占用时直接打开已有地址并退出。
- 想换端口：`set PORT=5000` 后再启动。

平时改代码用开发模式：

```
npm run dev
```

它同时起本地服务（4173）和 Vite 热更新（5173），日常写界面走 5173。

## 数据存在哪

| 文件 | 说明 |
|---|---|
| `data/app-data.json` | 全部数据，一个 JSON 文件 |
| `data/app-data.json.bak` | 上一次保存前的副本 |
| `data/backups/app-YYYYMMDD.json` | 每天第一笔编辑前的自动备份，最多留 14 份 |
| `data/app-data.pre-import-*.json` | 每次导入前自动存档 |
| `data/app-data.pre-reset-*.json` | 每次清空前自动存档 |
| `data/app-data.corrupt-*.json` | 数据损坏后以空白重建时，坏文件被挪到这里 |

想整体搬走，直接拷 `data` 目录即可。

## 备份与恢复

- **导出**：数据与设置 → 导出 JSON，得到一份完整快照。
- **导入**：数据与设置 → 导入，先校验结构并显示「将覆盖 N 条」，确认前会自动备份当前数据。
- **自动备份**：每天第一次编辑时留一份，设置页可一键恢复，恢复前也会先保存当前状态。
- **清空**：必须输入「清空」两个字；清空前自动存档。
- **数据坏了**：如果 `app-data.json` 被改坏，程序进入只读保护，不会覆盖原文件，页面上会列出备份供恢复，也可以选择以空白数据重建。

## 页面

首页总览 / 今日计划 / 自媒体 / 开发工作 / 咨询工作 / 健身计划 / 饮食计划 / 游戏娱乐 / 数据与设置。

每个模块的字段和操作按各自场景设计，不是同一张任务表换名字；模块里的东西可以「加入今天」，勾掉后回写源实体（自媒体内容只作提醒，不改阶段）。

## 测试

```
npm run test        # 全部单元与集成测试
npm run typecheck   # 类型检查
npm run build       # 类型检查 + 生产构建
```

测试覆盖存储层（原子写入、备份、损坏保护、导入导出往返）、计划回写规则、各模块业务逻辑、九个页面交互、命令面板与快捷键。

## 技术构成

- 前端：Vue 3 + TypeScript + Vite，无 UI 库、无图表库、无日期库。
- 后端：Node 内置 `http`/`fs`，只监听 `127.0.0.1`，负责静态文件、读写 JSON、备份与恢复。
- 存储：单文件 JSON，整包防抖保存（300ms），写入走「先备份 → 写临时文件 → 回读校验 → 重命名替换」。

目录：

```
server/     本地服务：http 骨架、JSON 存储、API
shared/     前端与服务端共用的 schema
src/        前端源码（views 页面、features 各模块、components 通用件、store 状态）
tests/      vitest 测试
data/       运行时生成的数据与备份
```

## 边界

- 单人单机使用，不做多用户、协作、分享。
- 只面向桌面浏览器，窗口宽度 1024 起；更窄会横向滚动，不做手机适配。
- 不联网、不抓取平台数据，自媒体播放量等靠手动回填。
